# Interactive review instructions

Open [the existing Living Glass prototype](../prototype/index.html). The prototype is now Arc-only. The upper toolbar is authoring UI, separate from exhibition controls.

1. Start at **B · Controlled spatial**, Gallery, English. Turn on Hit regions: six wrapper outlines should stay stationary while only art inside them responds. Hover across all six. Move the pointer gently within one portrait and compare its pose to the stable outline.
2. Change to **A · Restrained optical** without changing target. Compare the same Arc, artwork crop, theme and typography. B adds bounded tilt/parallax/lift; A emphasizes illumination and minimal scale/lift. The treatment switch must not change the chosen functional state.
3. Use Review performer to select GAIA, then **Neutral → Acquire → Stable target**. Acquisition stays local; stable targeting introduces cyan/turquoise. Repeat for every performer. **Next theme** demonstrates direct performer-to-performer blends without a neutral flash.
4. Select GAIA and choose **Run theme → Focus**. This explicitly scripted review sequence demonstrates neutral, acquisition, stable atmosphere, confirmation, portrait prominence, gallery recession and Focus. Repeat for all six. Pointer or new review intent interrupts the sequence. These authoring delays are not detector thresholds.
5. Use **Observation gap**: the last atmosphere should hold while fist confirmation is suspended. Use **Target-loss state**: only this semantic event initiates rest/neutral. Recover, point again, then confirm. No camera is running.
6. Open Settings/AI while a theme is stable. Observe common neutral reading glass, quiet context accents and suppressed gallery movement. Close mid-expansion, minimize/restore, and use Escape. Background input must stay scoped until dismissal. A fresh gesture target is required afterwards.
7. Repeat in 繁體中文, Reduced motion and Opaque fallback. Reduced motion removes spatial effects, not acquisition/confirmation/cancellation meaning. Opaque mode removes atmosphere/reflection, not identification.
8. Existing chapter review events still cover Activation, portrait preparation, still-art first-frame specimen, explicit completion and cancellation. No source camera, video player, live assistant or deferred preference is connected.
